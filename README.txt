1. OVERVIEW
------------------------------------------------------------
CoreBrand is a corporate-style static website built with HTML, CSS, and JavaScript. The site features a clean and responsive design aimed at showcasing company details, services, team members, and more.

This version includes detailed internal documentation in the form of code comments to help developers and designers understand the structure, functionality, and styling of each part of the site.

------------------------------------------------------------
2. TECHNOLOGIES USED
------------------------------------------------------------
- HTML5
- CSS3 (including internal styles and external stylesheet)
- JavaScript (for interactivity and enhancements)
- Font Awesome (icon library)
- Google Fonts (Poppins)

------------------------------------------------------------
3. FILE STRUCTURE
------------------------------------------------------------
core-website/
├── about.html               --> About Us page with story, mission, values, and team section
├── csv.html                 --> Page for uploading and viewing CSV data (custom use case)
├── dashboard.html           --> Dashboard for data metrics or user interface panels
├── index.html               --> Home page of the site
├── profile.html             --> User profile page layout
├── restaurant-dashboard.html--> Specialized dashboard layout for restaurants
├── signup.html              --> User signup/registration form
├── css/
│   └── styles.css           --> All custom styling for the website
├── js/
│   └── main.js              --> Optional script for site interaction

------------------------------------------------------------
4. HOW TO RUN
------------------------------------------------------------
To view the website:
1. Download or clone the repository.
2. Open any `.html` file (starting with `index.html`) in a web browser.
3. Make sure you're connected to the internet to load:
   - Google Fonts
   - Font Awesome icons
   - Placeholder images

No server or build tools are needed since this is a static site.

------------------------------------------------------------
5. CUSTOMIZATION NOTES
------------------------------------------------------------
- Replace placeholder team member images with real ones.
- Update contact info in the footer (`about.html` and `index.html`).
- To change styling, edit `css/styles.css`.
- The layout is responsive and mobile-friendly using CSS grid and flexbox.
